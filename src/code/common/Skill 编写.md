是写给AI Agent看的操作手册，把"遇到某类问题该怎么处理"写成一个标准化的SKILL.md文件，AI就能按照你的规矩来执行特定任务。

## Skill 结构

Skill 不只是一个 Markdown 文件， 还可以包含一些执行脚本或依赖的资源文件等。

一份Skill文件夹的目录结构理应如下：

```txt
your-skill-name/
├── SKILL.md              # 必需 - 主文件
├── scripts/              # 可选 - 可执行脚本
│   └── validate.py
├── references/           # 可选 - 详细文档
│   └── api-guide.md
└── assets/               # 可选 - 模板等资源
    └── template.md
```

**SKILL.md**

其中最重要的就是 SKILL.md, 它是定义AI技能的唯一必需文件，AI根据它来识别、理解和执行技能。它由两部分组成：

1. **YAML 元数据 (YAML Frontmatter)**：文件开头的元数据区块，用于向AI描述“你是谁”和“何时该用你”。

   YAML 元数据包含一些关键字用来定义，下面两个是必须的，此外还有一些不常用的可选项，暂不介绍：

```txt
---
name: 唯一标识符，必须与所在文件夹名一致；仅限小写字母、数字和连字符(-) 1-64字符
description: 功能与触发场景描述 < 1024字符
---
```

2. **Markdown 正文 (Markdown Body)**：元数据之后的核心指令，详细告诉AI“具体要怎么做”。

   md 正文就是描述具体的约束技能，应包含分步骤的操作说明、输入输出示例及常见边界情况的处理。

**scripts 文件夹**

这个文件夹存放确定性执行的脚本，可以在 SKILL.md 中决定在需要精确执行的操作时调用这些脚本；

一个确定型脚本可以让每次输出结构统一，避免了ai自己编写脚本的随机性

**references 文件夹**

这个文件夹定义了一些项目或技能的参考文档，例如 API 参考、配置说明等，可以帮助ai更好的理解项目或技能的功能和使用方法，避免让ai自己去查找费时费力。

**assets 文件夹**

这个文件夹就是放一些有关这个技能的一些静态资源文件，例如模板文件、配置文件等。AI在生成代码时可以直接引用这些模板，保证输出符合规范。



## 编写技巧

1. 详细的编写 SKILL.md 的 description 字段，这个字段决定什么时候调用你的Skill。应当写明触发条件和能力范围，必要时可以增加什么条件下禁止使用。

2. 编写前可以让ai调研相关技能的最佳实践，或者直接让ai自己编写相关技能的SKILL.md文件，然后自己再调整为符合自己的需求。

3. 查看线上的 skill 市场，看看有没有现成的skill可以参考直接使用。 这里推荐两个 [skillsmp](https://skillsmp.com/zh)  或是 [skills.sh](https://www.skills.sh/)
