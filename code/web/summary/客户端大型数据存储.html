客户端大型数据存储

正2026/7/28大约 8 分钟

一般存储一些简单的键值对，我们会使用 localStorage； 而针对在客户端存储大型数据，也有对应的API即 indexedDB 可以使用。

IndexedDB

IndexedDB 是一个事务型数据库系统，用于在客户端存储大量的结构化数据和高性能搜索（建立索引）。

IndexedDB 具有以下特点：

  • 键值对储存： IndexedDB 内部采用对象仓库（object store）存放数据，且主键不能重复；

  • 异步： IndexedDB 的存储查询等操作都是异步的，不会阻塞浏览器；

  • 支持事务： 事务操作只有都成功才执行，只要有一步失败，整个事务就都取消，数据库回滚到事务发生之前的状态，不存在只改写一部分数据的情况；

  • 同源限制： 每一个数据库对应创建它的域名，不能跨域访问；

  • 存储空间大： 相比于 localStorage （5MB），其存储空间至少250MB或更多；

  • 支持二进制储存： IndexedDB 不仅可以储存字符串，还可以储存二进制数据（ArrayBuffer 对象和 Blob 对象）。

IndexedDB 内含有多个对象接口，每个对象接口都负责一部分功能，下面列出常用的部分，具体每部分如何使用在后面指出：

  • 数据库：IDBDatabase 对象
  • 对象仓库：IDBObjectStore 对象 （表）
  • 索引： IDBIndex 对象
  • 事务： IDBTransaction 对象
  • 操作请求：IDBRequest 对象
  • 指针： IDBCursor 对象 （游标）
  • 主键集合：IDBKeyRange 对象

打开数据库与建表

let db;

// 打开数据库
// 1. 第一个参数是数据库名，没有就创建一个
// 2. 第二个参数是数据库版本号，当数据库表结构变更时，就应该更新版本号
const request = window.indexedDB.open('MyTestDatabase', 1);

request.onerror = (event) => {
    // 数据库打开异常
};
request.onsuccess = (event) => {
    // 数据库打开成功
    db = event.target.result;
};

// 创建新数据库或提高现有数据库版本号时，会触发upgradeneeded事件
request.onupgradeneeded = (event) => {
    const db = event.target.result;

    // 数据库升级会自动包含旧表
    // 一般新建数据库后，第一部操作就是创建 对象仓库（表） 指定主键为 myKey
    const objectStore = db.createObjectStore('name', { keyPath: 'myKey' });

    // 如果数据没有合适的主键，可以配置自动生成，指定主键为一个递增的整数。
    // const objStore = db.createObjectStore("names", { autoIncrement: true });

    // 为表字段指定索引，方便后续查找
    objectStore.createIndex('name', 'name', { unique: false });
    objectStore.createIndex('email', 'email', { unique: true });
};

数据的增删改查

执行数据库的任何操作前，都需要开启事务。 事务有三种模式：readonly、readwrite 和 versionchange；前两种对应表数据的增删改查，最后一种对应修改表结构模型。

// 1.添加  add方法
function add() {
    const request = db
        .transaction(['person'], 'readwrite')
        .objectStore('person')
        .add({ id: 1, name: '张三', age: 24, email: 'zhangsan@example.com' });

    request.onsuccess = function (event) {
        console.log('数据写入成功');
    };

    request.onerror = function (event) {
        console.log('数据写入失败');
    };
}

// 2.删除   delete方法
function remove() {
    var request = db.transaction(['person'], 'readwrite').objectStore('person').delete(1);

    request.onsuccess = function (event) {
        console.log('数据删除成功');
    };
}

// 3.更新  put方法
function update() {
    var request = db
        .transaction(['person'], 'readwrite')
        .objectStore('person')
        .put({ id: 1, name: '李四', age: 35, email: 'lisi@example.com' });

    request.onsuccess = function (event) {
        console.log('数据更新成功');
    };

    request.onerror = function (event) {
        console.log('数据更新失败');
    };
}

// 4.查询   get方法 入参为主键

使用索引

当我们明确知道需要查询或修改的主键时，很方便就可以查找到，但是当需要根据一个筛选条件取查询时，没有明确的主键，就需要使用索引。

创建索引就相当于数据库又维护了一张按“索引字段”排序的列表，并记录对应数据的主键值。查找索引时先从索引列表里筛选，获取到过滤后数据的对应主键在查value。

索引可以让你搜索任意字段，也就是说从任意字段拿到数据记录。如果不建立索引，默认只能搜索主键（即从主键取值）。

// 首先，确保你已在 request.onupgradeneeded 中创建索引：
// objectStore.createIndex("name", "name");
// 否则会抛出 DOMException。

const index = objectStore.index('name');

// 默认取查到的第一条
index.get('Donna').onsuccess = (event) => {
    console.log(`Donna 的社保号为 ${event.target.result.ssn}`);
};

由于索引值可能不唯一，所以当我们希望拿到查询索引值对应所有的数据列表时，还是需要使用 指游标 IDBCursor

// 用普通游标拿到完整客户记录对象
index.openCursor().onsuccess = (event) => {
    const cursor = event.target.result;
    if (cursor) {
        // cursor.key 是名字（如“Bill”），cursor.value 是完整对象。
        console.log(`Name：${cursor.key}，SSN：${cursor.value.ssn}，email：${cursor.value.email}`);
        cursor.continue();
    }
};

// 用键游标拿到客户记录对象的键
index.openKeyCursor().onsuccess = (event) => {
    const cursor = event.target.result;
    if (cursor) {
        // cursor.key 是名字（如“Bill”），cursor.primaryKey 是 主键。
        // 无法直接拿到已存对象的其余部分。
        console.log(`Name：${cursor.key}，主键：${cursor.primaryKey}`);
        cursor.continue();
    }
};

当然也能根据多个属性创建复合索引,查询时也需要按创建时的顺序传入查询的索引值数组。

const index = objectStore.createIndex('name_email', ['name', 'email']);

index.get(['Donna', 'donna@home.org']).onsuccess = (event) => {
    console.log(event.target.result);
    // {ssn: '555-55-5555', name: 'Donna', age: 32, email: 'donna@home.org'}
};

这里只是对 indexedDB 的原生API 的使用进行了基础的介绍，更详细的具体使用方法参考 MDN indexedDB

Dexie.js

由于原生 indexedDB 的API过于底层且繁琐，依赖各种回调函数处理，所以真实项目中一般使用 封装库 来对 indexedDB 进行操作，主流库是 Dexie.js

npm install dexie

打开数据库与建表

import Dexie from 'dexie';

// 创建（或打开）名为 "MyDatabase" 的数据库
const db = new Dexie('MyDatabase');

// 定义版本 3 的 schema
db.version(3).stores({
    friends: '++id, name, age', // friends 表，主键为自增 id，索引 name 和 age
    products: '++id, name, price', // products 表
});

// 打开数据库（也可以省略，首次查询时会自动打开）
db.open();

具体建表指定的传递的字符串，默认第一个是主键，其他的是索引。且只需要声明需要用于查询（where 条件）的字段，不需要像 SQL 那样把所有字段都列出来。

语法含义
++id自增主键
id手动指定的主键（不自增）
name普通索引
&email唯一索引（& 表示 unique）
*tags多值索引（数组索引），用于数组字段的查询
[firstName+lastName]复合索引（联合索引）

如果使用typescript，需要在建表时指定字段的类型，方便后续对表字段进行提示：

import Dexie, { type EntityTable } from 'dexie';

interface Friend {
    id: number;
    name: string;
    age: number;
}

const db = new Dexie('FriendsDatabase') as Dexie & {
    friends: EntityTable<Friend, 'id'>; // 'id' 是主键
};

db.version(3).stores({
    friends: '++id, name, age',
});

export { db };
export type { Friend };

数据的增删改查

/** -----------------------新增相关------------------------ */
// 单条新增
const id = await db.friends.add({ name: 'John Doe', age: 30 });
// 批量新增
const newFriends = [
    { name: 'Alice', age: 25 },
    { name: 'Bob', age: 30 },
];
const ids = await db.friends.bulkAdd(newFriends);

/** -----------------------删除相关------------------------ */
// 单条删除  参数是主键值
const result = await db.friends.delete(1); // result 为 true 表示成功
// 筛选后删除，按主键范围批量删除
await db.friends.where('id').between(3, 5).delete();
// 清空表
await db.friends.clear();

/** -----------------------更新相关------------------------ */
// 单挑更新  按主键更新指定字段
const updated = await db.friends.update(1, { age: 31 }); // result 为 true 表示成功
// put 会用整个对象替换，主键必须存在
await db.friends.put({ id: 1, name: 'Foo', age: 33 });
// 批量更新
await db.friends
    .where('age')
    .below(35)
    .modify((friend) => {
        friend.age = 35;
    });

/** -----------------------查询相关------------------------ */
// 查询单条记录  入参为主键值
const friend = await db.friends.get(1);

// 查询所有记录
const allFriends = await db.friends.toArray();

// 按条件查询，需先创建索引，再查询   名字以"张"开头
const zhangFriends = await db.friends
  .where('name')
  .startsWith('张')
  .toArray();

条件筛选

dexie 提供了许多 where 方法后可以继续调用的方法，用于筛选查询条件，下面列举出常用的一些。

方法含义
startsWith以指定字符串开头的记录
startsWithAnyOf以任意一个指定字符串开头的记录（传入数组）
endsWith以指定字符串结尾的记录
endsWithAnyOf以任意一个指定字符串结尾的记录（传入数组）
equals等于指定值
notEqual不等于指定值
below小于指定值
belowOrEqual小于等于指定值
above大于指定值
aboveOrEqual大于等于指定值
between在指定范围内（包含左边界，不包含右边界）
anyOf匹配任意一个指定值（传入数组）
noneOf不匹配任意一个指定值（传入数组）
equalsIgnoreCase忽略大小写相等
startsWithIgnoreCase忽略大小写以指定字符串开头

调用以上方法后，会返回一个 Collection 对象，可以继续链式调用以下方法执行最终操作：

  • toArray(): 返回结果数组。
  • count(): 返回结果总数。
  • each(callback): 遍历每条记录。
  • modify(changes): 批量修改数据。
  • delete(): 批量删除数据。
  • offset(n): 跳过前 n 条记录。
  • limit(n): 限制返回 n 条记录。
  • sortBy(key): 对结果排序。
  • reverse(): 反转结果顺序。
  • and(filterFn): 添加额外的JavaScript过滤条件

事务

Dexie.js 支持事务，确保多个操作的原子性。 第一个参数是事务类型，rw 读写 r 只读

await db.transaction('rw', db.friends, db.products, async () => {
  // 在同一个事务中操作多张表
  await db.friends.add({ name: '李四', age: 28 });
  await db.products.add({ name: '笔记本电脑', price: 5999 });
}).catch(error => {
  console.error('事务失败:', error);
});

修改表结构

当数据库表结构变更时，应该更新版本号。

// 假设现在版本号为 1
db.version(2).stores({friends: "++id,shoeSize,firstName,lastName"}).upgrade(tx => {
    return tx.table("friends").toCollection().modify(friend => {
        // 后续可以遍历所有数据，调整表结构字段值
        friend.firstName = friend.name.split(' ')[0];
        friend.lastName = friend.name.split(' ')[1];
        delete friend.name;
    });
});
